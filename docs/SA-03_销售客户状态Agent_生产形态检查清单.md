# 生产形态检查清单

## 已实现

- API 请求体上限 60MB，上传接口内部仍限制单文件 10MB、单批 50MB；
- 上传文件名净化、路径穿越防护、同名文件原子拒绝覆盖；
- JWT 认证、角色门禁、Argon2 密码哈希、生产环境密钥/初始密码校验；
- 基础安全响应头：`nosniff`、`DENY`、`no-referrer`；
- 分页参数有明确上下界，避免无界查询；
- 生产环境禁止 watcher 使用 `bypassPermissions`；默认使用 `acceptEdits`；
- 客户状态事实追加事件、负责人确认、撤回/更正/过期均可审计；
- 敏感数字不进入普通 Agent、日志、trace 和向量索引。

## 进入真实试点前仍需完成

- 由部署方提供密钥管理系统和密文轮换策略；
- 为 Claude Code 配置明确的 `allowedTools`、工作目录沙箱和最小文件权限；
- 反向代理 HTTPS、限流、WAF 和备份恢复演练；
- 使用真实脱敏样本补足状态建议准确率、人工修改率和延迟基线；
- 处理现有搜索接口测试中的未认证超长查询 `401/422` 语义统一问题；
- 对多副本 watcher 增加分布式锁，避免同一触发队列被重复消费。

## 面试中的诚实表述

本项目已经具备生产形态的边界控制和可回放闭环，但不是已上线的企业生产系统。已验证的是数据分层、人工门禁、审计、幂等、事件历史和合成回放；尚未验证的是真实业务准确率、供应商账单成本、并发容量和企业部署合规。
